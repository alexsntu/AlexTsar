# Портал автопарка (рефрижераторы)

Локальный стенд, который переезжает на VPS без переделки: учёт топлива, ТО и
ремонтов, маршрутные листы/задания водителям — всё в своём лёгком
приложении, за одной стартовой страницей.

## Состав стека

| Сервис | Что это | Локальный адрес |
|---|---|---|
| **Портал** | Стартовая страница со ссылками | http://localhost:8888 |
| **Fleet App** | Топливо, ТО и ремонт, рейсы и задания водителям, PWA (можно поставить на телефон) | http://localhost:8000 |
| **LubeLogger** | Поднят про запас, сейчас не используется — ТО/ремонт ведём в Fleet App | http://localhost:8181 |

Fleet App — это своё лёгкое приложение (Node.js/Fastify + SQLite на бэкенде,
React/PWA на фронтенде), а не ERPNext: один компактный контейнер вместо
десятка, вся логика — под нашим контролем. Подробности архитектуры — в
`app/README.md` (если понадобится) и в исходниках `app/server`, `app/web`.

## Быстрый старт

```bash
cd fleet-portal
docker compose -p fleet up -d --build   # собрать и поднять всё
docker compose -p fleet ps               # проверить статусы
docker compose -p fleet down             # остановить (данные сохраняются в volume)
docker compose -p fleet down -v          # остановить И стереть все данные (осторожно)
```

Если Docker не запущен: `colima start` (один раз после перезагрузки Мака).

При первом запуске Fleet App сам применяет миграции БД и создаёт
администратора (логин/пароль — из `.env`, см. `FLEET_ADMIN_EMAIL` /
`FLEET_ADMIN_PASSWORD`). Пересобирать образ вручную не нужно — `docker
compose up -d --build` делает это автоматически при изменении кода в `app/`.

## Доступы

- **Fleet App**: логин — значение `FLEET_ADMIN_EMAIL` из `.env` (по умолчанию
  `admin@fleet.local`), пароль — `FLEET_ADMIN_PASSWORD`.
- **LubeLogger**: при первом заходе на http://localhost:8181 попросит создать
  учётную запись администратора — это нормально, приложение свежее.
- Пароли и секреты лежат в `.env` (файл не коммитится в git, см.
  `.gitignore`).

## Первые шаги в Fleet App

1. Войдите под администратором.
2. В разделе **Справочники** заведите тягачи (название + госномер), водителей
   (ФИО + телефон) и виды топлива (например, «Дизель», «АИ-95»).
3. В разделе **Топливо** → вкладка «Приход» внесите закупки топлива (дата,
   вид, литры, цена за литр или сумма) — списание позже будет считаться по
   FIFO (сначала расходуется самая старая по цене партия).
4. Там же, вкладка «Заправки» — фиксируйте заправку конкретной машины
   (списывается по FIFO) либо заправку личного авто (обязателен комментарий,
   в расходы предприятия не входит).
5. Вкладка «Отчёты» — текущий остаток по видам топлива, расход за период
   (с разбивкой «расходы предприятия» / «личное»), расход на 100 км по
   машине.
6. В разделе **ТО и ремонт** → вкладка «Напоминания» задайте интервал ТО
   каждой машине (по пробегу и/или по дням) кнопкой «Настроить» — там же
   видно, сколько осталось до следующего ТО и просрочки. Вкладка «Журнал» —
   вносите плановое ТО или внеплановый ремонт (пробег, что сделали/сломалось,
   список запчастей с ценой — сумма считается автоматически); при внесении
   ТО дата и пробег становятся новой точкой отсчёта для следующего
   напоминания. Вкладка «Отчёты» — расходы на ТО и ремонт за период, по
   машинам или по типу.
7. В разделе **Рейсы** диспетчер создаёт рейсы (дата, водитель, машина,
   маршрут, груз) — на телефоне водителя под его логином отображаются
   только его рейсы, там же можно сменить статус и сразу залить топливо в
   свою машину.
8. Каждому водителю нужен отдельный логин для входа в свой кабинет на
   телефоне — в **Справочниках** у каждого водителя есть кнопка «Завести
   логин» (email + пароль), там же можно сменить пароль позже.

> ТТН и Акты выполненных работ — печатные формы под конкретные реквизиты
> компании ещё предстоит сверстать, когда будет точный формат.

## LubeLogger

Поднят в стеке про запас, но сейчас не используется — учёт ТО и ремонтов
ведётся в разделе «ТО и ремонт» самого Fleet App. Если понадобится — доступен
на http://localhost:8181 (при первом входе создаст отдельного
администратора, база у него своя, не связана с Fleet App).

## Установка Fleet App на телефон (PWA)

Откройте http://<адрес>:8000 в браузере телефона (Chrome/Safari) → меню
браузера → «Добавить на экран Домой» / «Установить приложение». Дальше
запускается как обычное приложение, без адресной строки браузера.

## Перенос на VPS

1. **Арендуйте VPS**: минимум 1 vCPU / 2 ГБ RAM достаточно (Fleet App лёгкий;
   если парк вырастет — 2 vCPU / 4 ГБ с запасом) с чистым Ubuntu 22.04/24.04,
   установите Docker Engine + Docker Compose plugin
   (`curl -fsSL https://get.docker.com | sh`).
2. **Скопируйте проект** на VPS (`git clone` вашего репозитория).
3. **DNS**: заведите поддомены на IP VPS — `example.ru`, `app.example.ru`,
   `garage.example.ru`.
4. **В `.env` добавьте**:
   ```
   DOMAIN=example.ru
   ACME_EMAIL=you@example.ru
   ```
5. **Смените секреты** в `.env` (`FLEET_JWT_SECRET`, `FLEET_ADMIN_PASSWORD`)
   на новые, продовые — сгенерировать можно так:
   ```
   openssl rand -hex 32   # для FLEET_JWT_SECRET
   openssl rand -base64 18 | tr -d '=+/'   # для FLEET_ADMIN_PASSWORD
   ```
6. **Запуск с HTTPS через Traefik** (оверлей уже готов):
   ```bash
   docker compose -p fleet -f docker-compose.yml -f docker-compose.vps.yml up -d --build
   ```
   Traefik сам получит сертификаты Let's Encrypt для всех доменов.
7. **Firewall**: откройте только 80/443 (и 22 для SSH) —
   `ufw allow 80,443,22/tcp && ufw enable`.
8. **Бэкапы** (важно настроить сразу):
   - Fleet App: том `fleet-app-data` содержит один файл SQLite —
     `docker run --rm -v fleet_fleet-app-data:/data -v $PWD:/backup alpine tar czf /backup/fleet-app-$(date +%F).tar.gz /data`,
     повесьте на cron раз в сутки и копируйте наружу (S3-совместимое
     хранилище или другой сервер).
   - LubeLogger: бэкапить том `fleet_lubelogger-data` (SQLite-база и
     вложения) тем же способом.

## Структура проекта

```
fleet-portal/
├── docker-compose.yml       # основной стек (локально и на VPS)
├── docker-compose.vps.yml   # + Traefik/HTTPS для VPS (оверлей)
├── .env                      # пароли, секреты и порты (не коммитить)
├── app/                       # Fleet App: топливо, рейсы
│   ├── Dockerfile              # multi-stage сборка (frontend + backend в один образ)
│   ├── server/                 # backend: Fastify + Prisma + SQLite
│   └── web/                    # frontend: React + Vite + PWA
└── portal/
    └── index.html             # стартовая страница
```
