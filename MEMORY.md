### Требования пользователя

- Итоговые документы должны повторять внешний вид и форматирование предоставленных июльских образцов. При проверке оформления значения данных не являются критерием совпадения.
- Эталон счёта: лист **«39 коп»**, итог **5 554 372,39 ₽**. Лист «40 коп» не использовать.
- Если даты загружаемого листа не соответствуют его ожидаемому периоду, обработку остановить до дальнейших расчётов и записи. Сообщение должно объяснять ошибку и просить исправить и повторно загрузить файл.

### Реализовано

Основной код: `fleet-portal/app/server/src/modules/documents/`.

- `referenceLayouts.ts`: генерируемый каталог оформления четырёх форм, без значений ячеек, реквизитов и формул. Вручную не редактировать.
- `layout.ts`: создание листов со стилями, размерами, объединениями и параметрами печати; сдвиг итогов и подписей при изменении числа строк. Для дневных актов сохранены 24 индивидуальных варианта по номеру акта, далее используется базовый вариант.
- `xlsx.ts`: генераторы подставляют значения в оформленные ячейки. Не использовать присваивание `row.values`, которое сбрасывает стили ExcelJS.
- `writeDocumentWorkbook` в `layout.ts`: обязательный способ сохранения. Восстанавливает OOXML-параметры, теряемые ExcelJS: признаки автоматической высоты строк, базовый шрифт Normal, параметры страницы и bestFit. Базовый шрифт влияет на физическую ширину колонок при печати.
- `routes.ts`: выгрузка через `writeDocumentWorkbook`. Добавлена прямая зависимость `jszip`.
- Ранее добавлена проверка неверного периода импорта до обращения к расчётам/БД и инструкция повторной загрузки в интерфейсе. Проверка покрыта `test/documents-import.test.ts`.

### Пересборка оформления

Экстрактор перенесён из временной папки в `fleet-portal/app/server/scripts/extract-document-layouts.cjs`. Он включает форматирование результата; отдельный Python-скрипт не нужен.

Из `fleet-portal/app/server`:

```sh
npm run layouts:extract -- '/путь/к/каталогу/эталонов'
npm test
npm run build
```

Второй необязательный аргумент — альтернативный выходной `.ts` для сравнения. Проверено: пересборка из исходных июльских образцов побайтово воспроизводит текущий `referenceLayouts.ts`.

Для изменения оформления редактировать копии исходных XLSX и пересобирать каталог. Для изменения структуры формы дополнительно менять массив `specs` экстрактора, привязки ячеек в `xlsx.ts`, при необходимости сдвиги в `layout.ts` и тесты. Тексты и формулы не извлекаются. Привязка индексов листов и XML рассчитана на исходные книги; при перестройке книг её нужно проверить. Подробности: `fleet-portal/app/server/src/modules/documents/FORMATTING.md`.
